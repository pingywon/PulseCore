# v43 Pulse CoreS3 Web Custom Rhythms + SD Log Compile Check

This version is based on v42 and keeps the same feature direction.

## Main goal
Make sure this is a new version and reduce compile risk in Arduino IDE by adding explicit forward declarations for functions used before they are defined.

## Preserved from v42
- 3-channel model: G5 = VAC, G6 = PPM/Rhythm, G7 = Motor.
- No Bluetooth / BLE / WiFiProv.
- Local-first boot with setup AP + web portal.
- 20 built-in rhythms plus 5 custom web-recorded rhythm slots.
- Custom rhythms are web-configurable and durably saved.
- SD logs use /log/YYYY-MM-DD/YYYY-MM-DD.log.
- Custom rhythm actions are written to the SD log when SD is present.

## v43 compile-risk fixes
- APP_VERSION updated to v43-web-custom-rhythms-sdlog-compilecheck.
- Added explicit forward declarations for functions that are referenced before their definitions in the large .ino, including:
  - allOutputsOff()
  - logSdEvent()
  - ppmWaveValue()
  - changeRhythmSpeed()
  - startSetupAp() / stopSetupAp()
  - startWebServer() / stopWebServerNow()
  - refreshWifiScreenNow()
  - startBackgroundStaConnect()
  - handleRhythmApi()
  - handleCustomRhythmApi()
  - handleFavoriteApi()
  - handleLogList()
  - handleLogData()

A true Arduino/M5Stack compile cannot be run in this environment because the M5Stack ESP32 toolchain is not installed here. I did run local static syntax checks with a stubbed Arduino/M5Stack environment and checked brace/parenthesis balance.
