# 5_Pulse_CoreS3_Demo

## Overview
This folder contains iteration 5 of the PulseCore / Pluto 9000 CoreS3 demo software.

## Main changes
- Added Settings screen.
- Added light/dark theme toggle.
- Added 10-step backlight control.
- Kept two-step E-stop confirmation behavior.

## Files
- `5_Pulse_CoreS3_Demo.ino` — Arduino IDE sketch for this iteration.

## Notes
- Open the `.ino` file in Arduino IDE from this folder.
- Select the M5Stack CoreS3/CoreS3 SE board profile before uploading.
- Later iterations move closer to live hardware testing; verify wiring and output behavior before connecting valves, solenoids, pumps, or MOSFET boards.
