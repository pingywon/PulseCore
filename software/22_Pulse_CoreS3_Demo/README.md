# 22_Pulse_CoreS3_Demo

## Overview
This folder contains iteration 22 of the PulseCore / Pluto 9000 CoreS3 demo software.

## Main changes
- Added version label on the More screen.
- Simplified Set screen with icon-style theme toggle and backlight plus/minus.
- Improved WiFi screen with SSID/IP/webserver state.
- Added real bench-test output pin definitions for G5, G6, G7, and G18.
- Updated Milky animation concept with sideways milk spurt.

## Files
- `22_Pulse_CoreS3_Demo.ino` — Arduino IDE sketch for this iteration.

## Notes
- Open the `.ino` file in Arduino IDE from this folder.
- Select the M5Stack CoreS3/CoreS3 SE board profile before uploading.
- Later iterations move closer to live hardware testing; verify wiring and output behavior before connecting valves, solenoids, pumps, or MOSFET boards.
