# 16_Pulse_CoreS3_Demo

## Overview
This folder contains iteration 16 of the PulseCore / Pluto 9000 CoreS3 demo software.

## Main changes
- Made the web dashboard directly controllable.
- Added VAC/PPM web controls, Start/Stop, and E-stop.
- Added More section on the web page.
- Added guarded SD setup/formatter tool for Pluto-generated files.

## Files
- `16_Pulse_CoreS3_Demo.ino` — Arduino IDE sketch for this iteration.

## Notes
- Open the `.ino` file in Arduino IDE from this folder.
- Select the M5Stack CoreS3/CoreS3 SE board profile before uploading.
- Later iterations move closer to live hardware testing; verify wiring and output behavior before connecting valves, solenoids, pumps, or MOSFET boards.
