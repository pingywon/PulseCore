# 9_Pulse_CoreS3_Demo

## Overview
This folder contains iteration 9 of the PulseCore / Pluto 9000 CoreS3 demo software.

## Main changes
- Refined VAC and PPM hold increments.
- Improved PPM frequency visualization.
- Improved VAC target/ramp graph.
- Improved Milky boot animation with larger mascot and clearer motion.

## Files
- `9_Pulse_CoreS3_Demo.ino` — Arduino IDE sketch for this iteration.

## Notes
- Open the `.ino` file in Arduino IDE from this folder.
- Select the M5Stack CoreS3/CoreS3 SE board profile before uploading.
- Later iterations move closer to live hardware testing; verify wiring and output behavior before connecting valves, solenoids, pumps, or MOSFET boards.
