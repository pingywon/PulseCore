# 6_Pulse_CoreS3_Demo

## Overview
This folder contains iteration 6 of the PulseCore / Pluto 9000 CoreS3 demo software.

## Main changes
- Added press-and-hold scrolling for plus/minus controls.
- Increased VAC and PPM control button size.
- Reduced graph footprint on control screens.
- Moved E-stop so it does not block primary controls.

## Files
- `6_Pulse_CoreS3_Demo.ino` — Arduino IDE sketch for this iteration.

## Notes
- Open the `.ino` file in Arduino IDE from this folder.
- Select the M5Stack CoreS3/CoreS3 SE board profile before uploading.
- Later iterations move closer to live hardware testing; verify wiring and output behavior before connecting valves, solenoids, pumps, or MOSFET boards.
