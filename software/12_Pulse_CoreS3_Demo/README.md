# 12_Pulse_CoreS3_Demo

## Overview
This folder contains iteration 12 of the PulseCore / Pluto 9000 CoreS3 demo software.

## Main changes
- Expanded web page options and share control link.
- Simplified boot branding and removed extra boot wording.
- Increased text sizes across the app.
- Added more mobile-aware web controls.

## Files
- `12_Pulse_CoreS3_Demo.ino` — Arduino IDE sketch for this iteration.

## Notes
- Open the `.ino` file in Arduino IDE from this folder.
- Select the M5Stack CoreS3/CoreS3 SE board profile before uploading.
- Later iterations move closer to live hardware testing; verify wiring and output behavior before connecting valves, solenoids, pumps, or MOSFET boards.
