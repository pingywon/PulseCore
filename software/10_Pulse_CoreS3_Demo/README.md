# 10_Pulse_CoreS3_Demo

## Overview
This folder contains iteration 10 of the PulseCore / Pluto 9000 CoreS3 demo software.

## Main changes
- Reworked the app into a more complete dashboard-style mockup.
- Added cleaner home screen, VAC, PPM, Live, Manual Test, and Settings screens.
- Kept simulation-only output behavior.
- Improved boot mascot presentation.

## Files
- `10_Pulse_CoreS3_Demo.ino` — Arduino IDE sketch for this iteration.

## Notes
- Open the `.ino` file in Arduino IDE from this folder.
- Select the M5Stack CoreS3/CoreS3 SE board profile before uploading.
- Later iterations move closer to live hardware testing; verify wiring and output behavior before connecting valves, solenoids, pumps, or MOSFET boards.
