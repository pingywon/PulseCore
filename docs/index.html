Pluto 9000 by PulseCore.

The Pluto 9000 is a smart milking controller built for a smoother, more adjustable session. It gives the operator independent control over primary suction, pulse strength, pulse speed, hold, and release so the machine can be tuned for comfort instead of locked into one harsh rhythm.

Meet Milky.

Milky is the face of the Pluto 9000: clean, blue, cream, memorable, and easy to recognize. He sets the tone at the top of the site, then the product story takes over.

Pluto 9000 is built around a simple idea: a milker should not just pull. It should pull, pulse, hold, and release with intention.

Control the session, not just the motor.

A basic milker gives the operator limited control. Pluto 9000 separates the major parts of the session so the full feel can be shaped: how pressure builds, how vacuum pulls, how long the cycle holds, how strongly it pulses, and how gently it releases.

The five-part comfort cadence.

The Pluto 9000 rhythm is simple to explain because the phases are clear. Each part has a job, and the software gives the operator a way to tune the way those parts work together.

1
PressureA controlled build that starts the cycle cleanly instead of abruptly.
2
Vacuum PullThe working draw phase where suction is steady, readable, and adjustable.
3
HoldA deliberate dwell that helps the motion feel composed rather than jumpy.
4
PulseThe repeating squeeze-and-rest behavior that creates the familiar milking rhythm.
5
ReleaseThe let-go moment that helps the session reset more naturally between cycles.

Four solenoids. One smoother system.

Pluto 9000 uses four controlled air-path actions to shape the rhythm. The operator does not experience them as separate parts; the operator experiences better control, cleaner pulsing, softer transitions, and a release that feels deliberate.

Air-path control overview

The four actions work together to control the pull, rhythm, trim, and release behavior of the session.

1Main Vacuum Control

3Comfort Trim Control

4Release Control

Built for testing, tuning, and real use.

The current Pluto 9000 direction is practical: prove the pump, valves, release behavior, software controls, logging, service checks, and enclosure workflow before turning the controller into a final polished build.

Diagnostic mode

Service controls are intended to fire individual actions for setup, demos, and troubleshooting.

Event history

Button presses, errors, operating state, and key parameters can be recorded for review.

Physical safety

A real emergency release remains a physical requirement, separate from software convenience.

Clean wiring

The controller, pump driver, MOSFET valve drivers, buck converter, and valve wiring need to be clean enough to service.

Readable enclosure

The box should make ports, power, release, and control access obvious without making the system feel homemade.

Repeatable demo

The demo mode should clearly show pump response, solenoid response, pulse timing, and release behavior.

Future PCB path

Once the prototype is proven, the same architecture can be converted into a purpose-built board.

The release is the difference.

Any milker can pull. Pluto 9000 is built to pull and let go with intention. The release stage helps keep the session from feeling like one constant tug and gives the cadence a more complete, more comfortable shape.

Less abrupt

A controlled release softens the transition out of the working pull.

More complete

More premium

The machine feels refined because the end of the cycle is controlled as carefully as the beginning.
