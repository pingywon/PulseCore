Built like a tool, not a toy.

The goal is a clean controller that feels understandable from the first screen: set vacuum strength, set pulse rhythm, watch the system respond, and run diagnostics without digging through code.

01

Vacuum ramp display

A real-time line graph shows the controller moving toward the selected vacuum setting, then monitoring that level until the setting changes.

02

Pulse frequency graph

The PPM display focuses on rhythm, not height. It shows the pulse pattern scrolling over time so the user can see the heartbeat of the machine.

03

Manual diagnostics

A hidden service screen can test the pump MOSFET, pulse solenoid, suction valve, strength valve, release valve, and future outputs individually.

Simple operating flow

  • Power on the controller and confirm system status from the main screen.
  • Set vacuum strength using clear step controls instead of tiny, annoying increments.
  • Set pulses per minute and watch the rhythm graph scroll in real time.
  • Use the service menu when building, wiring, or troubleshooting each output.

Designed for a compact V1 build.

This one-page concept assumes a new-parts build, not reused original machine parts. The layout is meant for a small bench-built system that can later evolve into a cleaner enclosure.

V1

New parts only

Built around a newly sourced pump, new valves, new tubing, and a fresh controller box so the machine is repeatable and easier to document.

UI

Readable screen

Large values, direct controls, 10-step backlight brightness, and a settings page for display preferences.

DEV

Builder friendly

Every electrical output has a manual test mode, making wiring checks faster and reducing guesswork at the workbench.

Development note: PulseCore is shown here as a product concept page. Final pressure limits, animal safety rules, duty cycles, sanitation choices, enclosure design, and fail-safe behavior still need to be validated before any real-world use.
